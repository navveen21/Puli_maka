# Puli_maka
Puli‑Maka is a two‑player abstract board game where two red Pulies try to eliminate blue Makas by jumping over them. Pulies step to adjacent nodes or jump over a Maka along a valid two‑edge chain, removing it. Makas place from reserve or move one edge. First Puli turn moves both Pulies; Puli wins by eliminating twelve Makas.
